Conecta Supabase para abrir y actualizar la misma lista desde otros dispositivos.

Pega la clave pública publishable o la anon antigua. Nunca uses una clave secret o service_role. Ejecuta primero el SQL de configuración. El primer dispositivo que se registre será administrador; los demás solo podrán borrar sus propios productos.

Comparte este enlace: al abrirlo, el dispositivo se conecta solo. Cualquiera con el enlace puede editar la lista.

Esta página está abierta como archivo local. Publica la web y vuelve a abrirla con su dirección https para generar un enlace que funcione en el teléfono.
